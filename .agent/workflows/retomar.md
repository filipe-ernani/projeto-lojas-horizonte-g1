# /retomar

Use no começo de toda sessão. Objetivo: continuar de onde parou, sem inventar contexto.

1. Leia `AGENTS.md`, `docs/STATUS.md` e `docs/DECISIONS.md`.
2. Confira o código real: `git status`, `git log --oneline -10` e a lista de arquivos em `src/`. Se o `STATUS.md` disser uma coisa e o código outra, **o código vence**; avise o Caio da divergência.
3. Responda ao Caio em até 8 linhas:
   - fase atual e o que estava em andamento;
   - o que está quebrado ou pendente;
   - o próximo passo sugerido;
   - qualquer dúvida que impeça de continuar.
4. Espere a confirmação do Caio antes de editar arquivos.

Não leia o projeto inteiro. Leia só o que a próxima tarefa exige.
